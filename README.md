# EuroPocket public app

Deployment-only repository for https://baesejin.github.io/europocket/.

The three HTML entry points contain the same clean public app. Initial transactions are empty; user records stay in the browser under `europocket_pub_*` keys. Export backups regularly.

Development, private app sources, reports and backups belong in the private `lab_europocket` repository. Publish only files generated by `scripts/export_public.py`; never merge or copy the whole private repository here.

Old icon URLs and the legacy app manifest are retained for installed-app compatibility. External Tailwind and icon CDN dependencies still require connectivity when not already available.

Removing files from the current branch does not erase their previous Git history.
